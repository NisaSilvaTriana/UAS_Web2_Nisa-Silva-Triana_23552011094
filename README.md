# Website Sistem Informasi Publikasi Sekolah Dasar

## Deskripsi Proyek

Website Sistem Informasi Publikasi Sekolah Dasar merupakan aplikasi berbasis Laravel yang dirancang untuk memudahkan penyampaian informasi sekolah kepada siswa, orang tua, dan masyarakat luas. Website ini menyediakan fitur profil sekolah, berita, pengumuman, agenda, galeri, dan kontak, serta dilengkapi dengan halaman administrasi untuk mengelola seluruh konten secara mudah dan terpusat. Sistem ini dikembangkan sebagai media publikasi informasi sekolah yang bertujuan meningkatkan efektivitas pengelolaan dan penyampaian informasi.
